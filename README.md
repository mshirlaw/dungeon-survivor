# Dungeon Survivor

Dungeon Survivor is a clone of Vampire Survivors: an infinite top-down survival roguelike. Your character only moves, weapons fire automatically, and enemies arrive in growing waves.

## Status

Early development. Implemented so far:

- Player movement (8 directions) with a code-driven walk animation
- Camera that follows the player
- Infinitely tiling ground

See [PLAN.md](PLAN.md) for the full roadmap.

## Requirements

- [Godot](https://godotengine.org/) 4.7

## Running

1. Open `project.godot` in Godot.
2. Press F5 to run the project.

## Controls

| Action | Keys |
|---|---|
| Move | Arrow keys, WASD, or gamepad stick |
